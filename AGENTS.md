# AGENTS.md

## Purpose
This repository versions ADÜMÜN governance standards, profiles, templates and executable governance guidance.

## Operating rules
1. Do not invent enterprise governance semantics that are not grounded in an approved/candidate human source.
2. Declare maturity for every authority-bearing artifact: OBSERVED, CANDIDATE, PILOTED, STANDARDIZED or ENFORCED as applicable.
3. Material changes use branches and pull requests into `main`.
4. Do not accumulate dependent PRs in the same workstream. Merge/close the prerequisite PR before opening the next dependent PR unless an explicit parallelization exception is recorded.
5. Local validation/evidence remains mandatory; GitHub Actions are optional and must not be the only validation path.
6. Provider-specific profiles implement enterprise semantics; they do not redefine them.
7. Preserve predecessor/successor lineage during migration.
8. Templates declare the standard/profile/version they implement and do not become authority merely by being copied.
